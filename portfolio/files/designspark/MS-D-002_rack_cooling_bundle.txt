NOTE ON FORMAT
--------------
DesignSpark PCB uses a proprietary semi-binary file format (.pcb / .sch / .prj)
that cannot reliably be hand-authored outside the application. This bundle
provides the engineering deliverables (netlist + BOM + design rules + drill
table) that DesignSpark would generate on export, packaged as plain text so
the design intent is fully recoverable.

To recreate in DesignSpark:
  1. File -> New -> Project, name "MS-D-002_rack_cooling"
  2. Import this netlist via File -> Import -> Netlist (Tango/Protel format below)
  3. Use the BOM here to add components from the RS Components library
  4. Apply the design rules at the end of this file
